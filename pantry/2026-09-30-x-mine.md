# X mine: LibreCopy-Claude-Code competitors

## How this fills

1. Take the top 5 to 8 names from the latest competitor map.
2. Search X for praise and complaints tied to **named matrix capabilities** (reliability, cost, DX, permissions, memory, multi-agent, verify), not brand vibes alone.
3. Fetch primary posts; quote short snippets with `x.com` links. **Never invent engagement counts or sentiment %.**
4. Save as `YYYY-MM-DD-x-mine.md` (keep this TEMPLATE).

## Search log (what we tried)

- Fetch method: WebFetch on an `x.com` post URL returned HTTP 402 (tried on https://x.com/mintlify/status/1856746045453349277). Post text was fetched instead from X's own embed endpoint, `https://cdn.syndication.twimg.com/tweet-result?id=<post id>&token=a`, which returns the post's text, author and date. Links above are the `x.com` URLs of those posts. For long posts the endpoint returns only the opening text, and the snippets quote only what came back.
- WebSearch `site:x.com humanizer skill claude code AI writing`: hits used (dr_cintas, pors, shannholmberg, ZabihullahAtal). Others returned but not used: a Japanese-language post about humanizer, a post about a "Human Writing Mode" prompt list, and a general skills-library post.
- WebSearch `site:x.com mintlify llms.txt docs AI agents`: hits used (aakashgupta, mintlify launch post, dbabbs). Other Mintlify vendor posts returned but not used.
- WebSearch `site:x.com claude code documentation README AI slop em dashes`: hits used (Berniverse42, hvpandya). Other results were general Claude Code posts.
- WebSearch `site:x.com vale prose linter docs`: one relevant X post (joshmarinacci); the rest were non-X pages.
- WebSearch `site:x.com llms.txt nobody uses it crawlers don't read`: hits used (kazuhito, sengineland, csswizardry, HamelHusain).
- WebSearch `site:x.com AI generated documentation outdated wrong docs drift claude code`: hits used (dani_avila7, DataChaz, zeke). X articles in the results were not fetched.
- WebSearch `site:x.com "avoid-ai-writing" OR "doc-coauthoring" skill claude`: no X posts about either skill; results were an X article list and non-X pages. Empty for these two names.
- WebSearch `site:x.com claude code changelog release notes generate from git commits skill`: results were Claude Code release-log posts and a commit-message skill post; nothing about changelog or release-note skills in this domain. Empty for the theme.
- Tried `site:x.com gemini cli docs-writer skill documentation` and `site:x.com cursor rules README technical writing documentation`: not run, because the session's WebSearch budget was used up (the tool refused both calls). No X evidence for Gemini CLI `docs-writer` or the awesome-cursorrules docs rules in this run.
